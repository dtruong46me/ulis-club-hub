## 🚀 Quick Actions

### ✅ To Run (5 min)
```bash
# Option 1: Python
cd landing-page
python -m http.server 8000
# Visit: http://localhost:8000

# Option 2: VS Code
# Right-click index.html → Open with Live Server

# Option 3: Node
npm install -g http-server && http-server landing-page
```

### ✅ To Edit (5 min)
1. Open `assets/js/data.js`
2. Add/edit club object
3. Refresh browser

### ✅ To Deploy (2 min)
```bash
# Push to Vercel
git add .
git commit -m "Initial commit"
git push
# Vercel deploys automatically!
```
